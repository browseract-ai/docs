# Logged-in automation

## 适用场景

目标网站需要登录、企业 SSO、浏览器扩展、证书或本地 Chrome 中已有的账号状态。

## 最短路径

先查看可用浏览器和 Profile：

```bash
browser-act get-skills core --skill-version <version>
browser-act browser list
browser-act browser list-profiles
```

已有合适浏览器时直接开 session：

```bash
browser-act --session login-task browser open <browser-id> https://target.example.com
browser-act --session login-task state
```

## 常用命令

将本地登录状态导入独立浏览器：

```bash
browser-act browser import-profile <browser_id> <profile_id>
browser-act --session login-task browser open <browser_id> https://target.example.com
```

需要企业 SSO、证书或扩展时，使用 `chrome-direct`：

```bash
browser-act --session sso browser open <chrome-direct-id> https://internal.example.com
browser-act --session sso state
```

## 安全/失败处理

- Profile 导入前要确认，因为它复制登录相关状态。
- `chrome-direct` 会操作用户真实 Chrome，使用前要说明权限范围。
- 登录后任务结束必须关闭 session。
- 如果目标环境差异触发重新验证，升级到 headed 或 `remote-assist`。

```bash
browser-act --session sso remote-assist --objective "请完成企业 SSO 或 2FA"
```
