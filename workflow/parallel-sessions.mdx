# Parallel sessions

## 适用场景

需要同时监控多个页面、并行抓取多个目标、隔离不同任务上下文，或让多个 Agent/对话不互相干扰。

## 最短路径

同一浏览器上开多个 session：

```bash
browser-act --session task-a browser open <browser-id> https://site.com/page-a
browser-act --session task-b browser open <browser-id> https://site.com/page-b
browser-act --session task-a state
browser-act --session task-b state
```

## 常用命令

跨浏览器并行，适合多账号或完全隔离身份：

```bash
browser-act --session shop-a browser open <browser-a> https://competitor-a.com
browser-act --session shop-b browser open <browser-b> https://competitor-b.com
browser-act --session shop-a get markdown
browser-act --session shop-b get markdown
```

查看和关闭 session：

```bash
browser-act session list
browser-act --session task-a session close task-a
browser-act --session task-b session close task-b
```

## 安全/失败处理

- session 名称要描述任务，不要复用他人 session。
- 同账号并行优先用同浏览器多个 session；多账号隔离才使用不同浏览器。
- 任务完成后关闭每个 session。
- 如果发现已有 session，不确定所有权时创建新 session。
