# Protected content

## 适用场景

目标页面需要 JavaScript 渲染、普通请求被拦截、存在 Cloudflare/DataDome 类检测，或者需要特定地区出口 IP 才能访问。

## 最短路径

只读内容时先用无 session 路径：

```bash
browser-act stealth-extract https://protected-site.com
```

需要 HTML、代理或输出文件：

```bash
browser-act stealth-extract https://protected-site.com --content-type html
browser-act stealth-extract https://protected-site.com --dynamic-proxy US
browser-act stealth-extract https://protected-site.com --output ./result.md
```

## 常用命令

需要点击、输入、分页或登录后交互时，使用 stealth 浏览器：

```bash
browser-act browser create --type stealth --name "protected-task" --desc "受保护内容采集" --dynamic-proxy US
browser-act --session protected browser open <stealth-id> https://protected-site.com
browser-act --session protected state
browser-act --session protected click <index>
browser-act --session protected get markdown
browser-act --session protected session close protected
```

## 安全/失败处理

- 创建 stealth 浏览器和配置代理前需要用户确认。
- 如果页面弹验证码，先尝试 `solve-captcha`，失败再 `remote-assist`。
- 如果只需要读取内容，不要创建持久浏览器。

```bash
browser-act --session protected solve-captcha
browser-act --session protected remote-assist --objective "请完成验证码验证"
```
