### **What can you extract?**

✅ Text (headings, paragraphs, lists)

 ✅ Media (image URLs, links)

 ✅ Structured data (tables, lists)

 ✅ Element attributes (buttons, forms)

📅 **Coming soon:** Network requests, video downloads, CSS styles

**💡 Pro tip:** For hidden content, scroll first or click "Load More" buttons.

---

### Login-Protected Websites

Bots built with Agent or Workflow can use authorized account credentials. Standard Browser also supports cookie import and manual login. See [Website Login](/website-login/overview?co-from=link-Docs).

For email or SMS verification, complete the check yourself using [Manual login](/website-login/manual-login?co-from=link-Docs), or import cookies from a verified session. If a run has already failed, fix login and start a new run.

### How Much Data Can You Extract?

**Short answer:** Unlimited—billed by steps taken.

**Understanding costs:**

- Workflow Built Bots: **3 credits per executed step**.
- Standard actions: Click, Type, Navigate, Extract, Scroll, etc.

**Workflow step-cost example:**

- 5–10 executed steps = **15–30 credits**.
- Start with small test runs (verify accuracy)
- Then run in bulk (confirm stability)
- ⚠️ Recommend no more than 10,000 records per run

### Concurrent Executions

**How many tasks can run at once?**

- **Free users:** 1 concurrent task
- **Paid users:** Up to 20 concurrent tasks
