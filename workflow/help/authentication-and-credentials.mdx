Account credentials are supported for Bots built with Agent or Workflow. See [Use account credentials](/website-login/account-credentials?co-from=link-Docs) for the current setup and authorization steps.

Authenticator-app keys provide supported TOTP codes. For email or SMS verification, complete the check yourself using [Manual login](/website-login/manual-login?co-from=link-Docs), or import cookies from a verified session.
