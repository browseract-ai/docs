Account credentials are supported for Bots built with Agent or Workflow. See [Use account credentials](/website-login/overview?co-from=link-Docs#method-1-use-account-credentials) for the current setup and authorization steps.

Authenticator-app keys provide supported TOTP codes. For email or SMS verification, complete the check yourself using [Manual login](/website-login/overview?co-from=link-Docs#method-3-log-in-manually), or import cookies from a verified session.
