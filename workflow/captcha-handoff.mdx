# CAPTCHA handoff

## 适用场景

页面弹出验证码、2FA、硬件令牌、企业认证或其他必须人工判断的步骤。

## 最短路径

先尝试自动解决：

```bash
browser-act --session blocked solve-captcha
```

失败后升级到人工接力：

```bash
browser-act --session blocked remote-assist --objective "请完成验证码或 2FA"
```

## 常用命令

可视化本地窗口：

```bash
browser-act --session blocked browser open <browser-id> https://target.example.com --headed
```

远程协助：

```bash
browser-act --session blocked remote-assist --objective "请完成登录验证"
```

## 安全/失败处理

- `solve-captcha` 可能需要 API Key。
- `remote-assist` 返回远程 URL 后，Agent 必须暂停浏览器命令。
- 用户完成后，Agent 再运行 `state` 确认页面状态。
- 不要把用户在远程协助中输入的敏感信息写入文档、日志或输出。

```bash
browser-act --session blocked state
```
