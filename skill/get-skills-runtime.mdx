# get-skills Runtime

`get-skills` is the runtime instruction entry point. The Agent calls it first so it can see the current BrowserAct CLI state before choosing commands.

## Start with core

```bash
browser-act get-skills core --skill-version <version>
```

`core` returns the information most tasks need:

- CLI and Skill version compatibility
- API Key status
- Available browsers with `id`, `type`, and `desc`
- Active sessions
- Core browser interaction commands
- Safety and browser-selection rules based on the current state

## Load advanced only when needed

Use advanced guidance when the task needs profile import, proxy settings, private mode, network capture, or remote assist details.

```bash
browser-act get-skills advanced
```

Do not load advanced instructions by default. Keep the Agent's context focused on the current task.

## Use main for Skill updates

```bash
browser-act get-skills main
```

`main` returns the latest entry Skill content. Use it when the CLI reports that the installed Skill is out of date.

## Version matching

If the CLI or entry Skill is too old, `get-skills` can return an upgrade path. Follow that guidance before running browser commands.
