## What the Skill does

- Loads the right instructions at runtime through `get-skills`.
- Gives the agent the current browser, session, and CLI state.
- Guides the agent to use BrowserAct CLI with safety confirmations for sensitive actions.

## Skill and CLI Runtime

Skill is the agent-facing instruction layer.

CLI Runtime is the execution layer that actually opens pages, reads state, clicks, types, manages sessions, uses stealth mode, captures network requests, and handles handoff when needed.

## Minimum agent startup sequence

```bash
browser-act get-skills core --skill-version <version>
browser-act browser list
browser-act --session my-task browser open <browser-id> https://example.com
browser-act --session my-task state
browser-act --session my-task session close my-task
```

Ask for user confirmation before sensitive operations, such as creating or deleting browsers, importing profiles, changing proxy or privacy settings, or using a `confirm_before_use` browser.
