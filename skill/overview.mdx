为 AI Agent 打造的浏览器自动化 CLI。突破反爬封锁，受阻时跨平台远程人机接力。多任务并发提效，多会话并行互不影响，多账号隔离独立运行。

## 为什么需要 Browser-act

AI Agent 需要的浏览器，要能去标准工具去不了的地方、要在卡住时让人无缝接管、要在多任务并行时互不串号、要为 LLM 推理而非人类脚本设计。

**给 Agent 用的浏览器，必须做对四件事：**

### 1. 突破封锁——三层递进

- **环境层** — stealth 指纹伪装、TLS 轮换、代理切换。绝大多数封锁压根不会触发
- **执行层** — `solve-captcha` 自动破解验证码；`stealth-extract` 一行命令提取受保护页面
- **人工层** — `remote-assist` 生成实时链接，任意设备接管，处理完 Agent 无缝继续

### 2. 三种浏览器形态——按真实场景分

- **`chrome`** — 复用本地 Chrome 登录态（导入 Profile / CDP 直连两种模式）
- **`stealth` 隐私模式** — 每会话全新指纹 + 代理轮换，无登录大批量抓取无阻碍
- **`stealth` 固定身份** — 固定指纹 + 固定 IP，登录账号多浏览器并行身份不被关联

### 3. 并发零干扰——每个 Agent 独立车道

- **跨浏览器并行** — 独立 Cookie / 指纹 / 代理，网站无法关联
- **同浏览器多会话** — 共享登录态独立执行，互不卡住
- **隐私模式** — 每会话全新指纹 + 空 Profile，运行结束零残留

### 4. 为 Agent 推理而设计——不是给人写脚本

- **紧凑文本输出** — 索引化文本格式，比 JSON / HTML 节省数倍 Token
- **索引化交互** — `state` 返回索引列表，`click 3` / `input 2 "..."`，无需解析 DOM
- **语义化记忆** — 浏览器带 `desc`，按任务语义匹配
- **并发安全** — 会话归属 + 显式命名，多 Agent 不冲突

## 不止于此

- **跨平台远程人机接管** — 任意设备打开链接即接管，处理完 Agent 无缝继续
- **Skill Forge — 你的专属爬虫工程师** — 探索一次生成可部署 Skill，反复跑同一稳定路径
