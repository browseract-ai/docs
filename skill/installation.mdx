## Agent 集成（推荐）

直接告诉你的 AI Agent：

> 帮我安装 browser-act，Skill 地址：https://github.com/browser-act/skills/tree/main/browser-act ，安装成功后检测可用性。

Agent 会自动完成 CLI 安装、Skill 配置，并验证是否可正常使用。

## 手动安装

```bash
uv tool install browser-act-cli --python 3.12
```

验证安装：

```bash
browser-act --version
```

## 认证（可选）

API Key 解锁以下功能：

- **stealth 浏览器** — 反检测指纹伪装浏览
- **stealth-extract** — 一条命令提取受保护页面内容
- **动态代理** — 托管 IP 轮换，按区域自动分配
- **solve-captcha** — 自动验证码解决

不认证也可正常使用 chrome 和 chrome-direct 浏览器。

获取 API Key：

```bash
browser-act auth login
# 打开注册链接 → 完成注册 → 轮询获取 Key
browser-act auth poll
```

或直接设置：

```bash
browser-act auth set <your-api-key>
```

## 升级

```bash
uv tool upgrade browser-act-cli
```

Skill 层自动检测 CLI 与 Skill 内容的版本不匹配，并引导升级。

## 要求

- Python 3.12+
- Chrome/Chromium（用于 `chrome` 和 `chrome-direct` 类型）
- API Key（仅 `stealth` 类型需要）

## 故障排除

### 安装后找不到命令

确保 `uv` 工具目录在 PATH 中：

```bash
uv tool dir
# 将输出路径添加到 shell PATH
```

### 诊断

上传日志用于问题诊断：

```bash
browser-act report-log
```

发送改进建议：

```bash
browser-act feedback "问题或建议的描述"
```
