# Installation

This page helps you get BrowserAct ready for an Agent. You install the CLI, then verify that `get-skills` can return runtime-aware instructions.

## Agent setup

If your Agent supports Skills, give it this instruction:

```text
Install browser-act. Use this Skill URL: https://github.com/browser-act/skills/blob/main/browser-act/SKILL.md. After installation, verify that the CLI works.
```

The Agent should install or upgrade the BrowserAct CLI, add the entry Skill, and run a quick verification command.

## Manual setup

Install the CLI:

```bash
uv tool install browser-act
```

Upgrade it later with:

```bash
uv tool upgrade browser-act
```

Check that the command is available:

```bash
browser-act --version
```

## Optional authentication

You can use local `chrome` and `chrome-direct` without an API Key. An API Key is used for hosted capabilities such as stealth browser, dynamic proxy, CAPTCHA solving, and `stealth-extract`.

```bash
browser-act auth login
browser-act auth poll
```

You can also set a key directly:

```bash
browser-act auth set <your-api-key>
```

## Verify the Skill runtime

Run:

```bash
browser-act get-skills core --skill-version <version>
```

You should see CLI status, authentication status, available browsers, active sessions, safety rules, and core command guidance.

## Troubleshooting

If the command is not found, check that the `uv` tool directory is on your PATH:

```bash
uv tool dir
```

For diagnostics, upload logs:

```bash
browser-act report-log
```

## Requirements

- Python 3.10+
- Chrome or Chromium for `chrome` and `chrome-direct`
- API Key only for hosted stealth capabilities
