# Advanced Capabilities

Advanced capabilities help the Agent handle real browser automation work: logged-in pages, blocked steps, network inspection, proxy settings, and safe testing.

## Profile import

```bash
browser-act browser list-profiles
browser-act browser import-profile <browser_id> <profile_id>
```

Profile import copies login-related browser state such as cookies, localStorage, and IndexedDB. It does not copy history, bookmarks, extensions, cache, or saved passwords. The import is a snapshot, not live sync.

Ask for confirmation before importing a profile because it copies login-related state.

## Remote assist

```bash
browser-act --session s1 remote-assist --objective "Complete 2FA verification"
```

The CLI returns a live remote URL. The user can open it in a browser and take over the automated browser. The Agent should wait until the user says the manual step is complete.

## Proxy settings

```bash
browser-act browser create --type stealth --name s1 --desc "..." --dynamic-proxy US
browser-act browser update <id> --dynamic-proxy JP
browser-act browser update <id> --custom-proxy socks5://host:port
browser-act browser update <id> --no-proxy
```

Dynamic proxy and custom proxy are mutually exclusive. Proxy settings apply to stealth browser only.

## Network capture

```bash
browser-act --session s1 network requests
browser-act --session s1 network requests --type xhr,fetch
browser-act --session s1 network request <request_id>
browser-act --session s1 network har start
browser-act --session s1 network har stop ./capture.har
```

Use network capture to find API calls behind a page, debug authentication, or inspect XHR and fetch responses. HAR files can contain sensitive headers or request bodies, so review them before sharing.

## Cookies and offline mode

```bash
browser-act --session s1 cookies export ./cookies.json
browser-act --session s2 cookies import ./cookies.json
browser-act --session s1 network offline on
browser-act --session s1 network offline off
```

Offline mode can be used to test submit flows without sending real network requests.
