## 安装入口 Skill

告诉你的 Agent：

> 从 https://github.com/browser-act/skills/tree/main/browser-act 安装 browser-act Skill

Agent 会自动将 SKILL 文件下载到其 Skills 目录。安装完成后，Agent 即可感知 Browser-act 并在合适时机自动调用。

## 两层架构

```
┌─────────────────────────────────────────┐
│  入口 Skill（安装的文件）                │
│  轻量、稳定、极少变更                    │
│  教会 Agent："browser-act 存在"          │
├─────────────────────────────────────────┤
│  运行时内容（get-skills CLI）            │
│  环境感知、版本匹配                      │
│  教会 Agent："这样使用它"                │
└─────────────────────────────────────────┘
```

### 第一层：入口 Skill

安装到 Agent Skills 目录的文件。它刻意精简：
- 触发 Agent 对 Browser-act 的感知
- 包含触发词用于激活
- 将 Agent 指向 `get-skills` 获取实际指令

入口 Skill 很少变更——它是稳定入口。

### 第二层：通过 `get-skills` 获取运行时内容

Agent 的第一条命令必须始终是：

```bash
browser-act get-skills core --skill-version <version>
```

返回 Agent 当前会话所需的一切：
- **环境状态** — CLI 版本、API Key 状态
- **浏览器列表** — 所有可用浏览器及其 ID、类型、描述
- **活跃会话** — 正在运行的会话
- **核心命令** — 交互参考
- **指令** — 基于当前状态的动态规则

## 主题

| 命令 | 内容 | 何时使用 |
|------|------|----------|
| `get-skills core --skill-version <v>` | 核心工作流、命令、环境状态 | 总是第一个 |
| `get-skills advanced` | 代理、Profile、隐私模式、高级模式 | 当核心不够时 |
| `get-skills main` | 最新 SKILL.md 内容用于自更新 | 检测到版本不匹配时 |

## 渐进式加载

- **多数任务只需 `get-skills core`** — 覆盖 80% 使用场景
- **需要代理配置、Profile 导入等高级能力时** — 才按需加载 `get-skills advanced`
- 避免一次性灌入大量不相关信息

## 版本兼容

`--skill-version` 参数让 CLI 检测不兼容：

```bash
# Skill 声称是 2.0.2 版本
browser-act get-skills core --skill-version 2.0.2
```

如果 CLI 版本与 Skill 版本不兼容，输出包含升级指引：
- CLI 过旧 → `uv tool upgrade browser-act-cli`
- Skill 过旧 → `browser-act get-skills main` 获取最新 Skill 内容

版本兼容是自动的：Skill 文件声明版本号，CLI 检查兼容性。不兼容时输出中直接包含升级指引，Agent 自动执行。

## 动态指令

`get-skills` 输出包含"指令"——基于当前状态生成的上下文规则：

| 指令 | 触发条件 |
|------|---------|
| **多浏览器指令** | 多个浏览器存在时，提供基于 `desc` 匹配的选择引导 |
| **会话指令** | 发现已有会话时，提醒 Agent 所有权规则 |
| **认证指令** | API Key 缺失时，引导远离 stealth 操作 |

指令是 Browser-act 根据 Agent 当前情况调整引导的机制，无需在 Skill 中硬编码每种场景。

## 从 Agent 视角看的工作流

```
1. 用户说 "查一下 example.com 的价格"
2. Agent 的入口 Skill 激活（触发词匹配）
3. Agent 运行：browser-act get-skills core --skill-version 2.0.2
4. Agent 收到：环境状态 + 浏览器列表 + 命令 + 动态指令
5. Agent 选择合适的浏览器（desc 匹配）
6. Agent 向用户确认（确认门控）
7. Agent 执行浏览器操作
8. Agent 关闭会话，更新浏览器 desc
```

## Agent 兼容性

适用于任何能够：
1. 从 Skills 目录读取 SKILL 文件
2. 执行 Shell 命令
3. 解析文本输出

的 Agent。

兼容列表：
- **Claude Code** — SKILL.md 在 `.claude/skills/`
- **GitHub Copilot** — 通过 Skills 目录发现
- **Cursor** — Rules/Skills 目录
- **Windsurf** — Agent Skills 系统
- **Google Gemini CLI** — AGENTS.md 集成
- **OpenCode** — Skills 系统
- **Codex** — Skills 集成
