# Browser-act

Browser-act is a Skill-powered browser automation CLI for AI agents.

Skill 是 Agent 的第一入口；CLI 是执行运行时；浏览器、session、profile、network 和 security 是运行对象与安全模型。首版文档按这个顺序组织，而不是按传统 Learn / Help / API reference 展开。

## 先理解这三层

| 层 | 作用 | 你会看到的内容 |
| --- | --- | --- |
| Skill | 让 Agent 发现 Browser-act，并知道先加载运行时说明 | `skill/overview`、`skill/get-skills-runtime` |
| CLI runtime | 执行浏览器自动化命令 | `browser-act get-skills`、`browser-act --session ...` |
| Runtime objects | 控制真实浏览器状态与安全边界 | browser、session、profile、stealth、network、security |

## 最短路径

```bash
browser-act get-skills core --skill-version <version>
browser-act browser list
browser-act --session my-task browser open <browser-id> https://example.com
browser-act --session my-task state
browser-act --session my-task click 2
```
