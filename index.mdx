# Browser-act

Browser-act is a Skill-powered browser automation CLI for AI agents.

Skill is the Agent entry layer. CLI Runtime is the execution layer. Browsers, sessions, profiles, network capture, and security rules define how the runtime is used safely.

## Start with the three layers

| Layer | What it does | Where to read |
| --- | --- | --- |
| Skill | Helps the Agent discover BrowserAct and load runtime-aware instructions first | `skill/overview`, `skill/skills` |
| CLI Runtime | Performs browser automation commands | `browser-act get-skills`, `browser-act --session ...` |
| Runtime objects | Control browser state and safety boundaries | browser, session, profile, stealth browser, network capture, security |

## Shortest path

```bash
browser-act get-skills core --skill-version <version>
browser-act browser list
browser-act --session my-task browser open <browser-id> https://example.com
browser-act --session my-task state
browser-act --session my-task click 2
```
