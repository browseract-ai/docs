Browser and proxy settings control the environment a Bot uses when it runs. Use this section to configure browser behavior, session settings, network routes, and proxy options, and to troubleshoot access or performance issues.

## Browser

- **Quick Start:** Configure the browser before running a Bot.
- **Browser Modes and Profiles:** Choose the browser environment that matches the target website.
- **Runtime Environment:** Understand the environment used for each Task.
- **Best Practices:** Improve reliability when websites load slowly or behave dynamically.
- **Performance and Maintenance:** Keep browser-based automation stable over time.
- **Troubleshooting:** Diagnose browser startup, page loading, and interaction problems.

## Proxy

- **Overview:** Compare BrowserAct Dynamic Proxy, Static Proxy, and Custom Proxy.
- **Static Proxy:** Purchase, manage, and assign a fixed IP to a Cloud Bot or Agent CLI browser.
- **Dynamic Proxy:** Configure rotating residential proxy access and select a region.
- **Custom Proxy:** Connect and validate a proxy from your own provider.
- **Best Practices:** Choose a browser and proxy combination for the task.

Browser and proxy configuration does not replace website authorization. Only automate pages you are permitted to access.
