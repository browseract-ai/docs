title: "Overview"
---

Account Credentials stores website login details for Bots built with Agent or Workflow. Manage account identifiers, passwords, supported authenticator-app keys, Bot permissions, and usage records in one place.

Authorize only the Bots that need access to each credential. Review or remove access when a Bot no longer needs it.

For credential creation, authorization, editing, and removal, see [Use account credentials](/website-login/overview?co-from=link-Docs#method-1-use-account-credentials).

To set up cookies or manual login instead, see [Website Login](/website-login/overview?co-from=link-Docs).
