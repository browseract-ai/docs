Bot Templates are ready-to-run Bots for common web data extraction and browser automation scenarios. Use a template as provided, return to it from your `Bots` list, or create an editable duplicate when you need to customize the Bot.

## What You Can Do

- Browse official templates in the BrowserAct Template Marketplace
- Enter your own runtime inputs and run a template immediately
- Review each run from the Bot's `History` tab or the account-level `Tasks` page
- Adjust supported browser and proxy settings
- Create an independent editable copy when you need to change fields, logic, or the target scenario

## Template Bots and Editable Duplicates

A template Bot keeps the official template structure read-only while allowing you to provide new inputs and maintain supported Browser Settings. `Create Editable Duplicate` creates a separate Agent Built Bot that you can modify independently.

Template Bots do not include the publisher's cookies, browser profiles, passwords, or API keys.
