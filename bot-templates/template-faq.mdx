title: "Template FAQ"
description: "Answers to common questions about BrowserAct Bot Templates."
---

## Can I edit a template Bot?

You can change the input values for each run. To change the extraction fields, logic, or target scenario, use `Create Editable Duplicate` to create an independent editable Bot.

## Will template updates overwrite my Bot settings or History?

No. Official template updates preserve the existing template Bot's settings and History. A Bot created with `Create Editable Duplicate` is independent and does not automatically receive later template updates.

## Can I publish my own Agent Built Bot as a public template?

Not currently. Users cannot publish Agent Built Bots directly to the public Template Marketplace.

## Can I use template Bots with Make, n8n, Zapier, API, or MCP?

Yes. Official template Bots can be called through Make, n8n, Zapier, the BrowserAct API, or MCP. Follow the setup instructions in [Integrations](/integrations/integration-overview) for the connection method you want to use.

## Can I change browser mode or proxy settings for a template Bot?

Yes. Open the template Bot and use `Browser Settings` to adjust the supported browser and proxy configuration.
