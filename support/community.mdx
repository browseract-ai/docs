Join the [BrowserAct Discord community](https://discord.com/invite/UpnCKd7GaU) to connect with BrowserAct users and the product team.

## Use the Community For

- Product and setup questions
- Workflow Built and Agent Built use cases
- Make, n8n, Zapier, and MCP discussions
- Sharing automation examples
- Product feedback and feature requests

## Before You Post

Search the Help Center and existing Discord discussions first. When asking about a failed Bot or Task, include:

- Bot ID and Task ID
- Target website
- Expected and actual behavior
- Relevant error message
- Screenshot with sensitive information removed

Do not post API keys, passwords, verification codes, stored credentials, or private account information in a public channel.

For an account, payment, or private product issue, create a support ticket or email [support@browseract.com](mailto:support@browseract.com).
