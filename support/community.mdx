Contact [BrowserAct online support](https://www.browseract.com/?support=messages&co-from=link-Docs) for product questions and feedback. If the panel does not open automatically, select the customer support button and open **Messages**.

## What You Can Ask About

- Product and setup questions
- Workflow Built and Agent Built use cases
- Make, n8n, Zapier, and MCP discussions
- Sharing automation examples
- Product feedback and feature requests

## Before You Contact Support

Search the Help Center first. When asking about a failed Bot or Task, include:

- Bot ID and Task ID
- Target website
- Expected and actual behavior
- Relevant error message
- Screenshot with sensitive information removed

Do not send API keys, passwords, verification codes, or stored credential secrets.

For an account or payment issue, contact online support or email [support@browseract.com](mailto:support@browseract.com).
