## FAQ Categories

- **Getting Started FAQ:** Product basics, login-protected pages, and build methods.
- **Bot FAQ:** Shared Bot behavior, Agent Built questions, Workflow Built login, verification, and troubleshooting paths.
- **Agent & Integrations FAQ:** Other AI agents, MCP, API keys, and integration availability.
- **Account, Billing & Credits FAQ:** Account boundaries, subscriptions, Credit Packs, invoices, infrastructure charges, rewards, and cancellation.
- **General Troubleshooting:** Task failures, login failures, missing data, and website changes.

For task, login, and extraction issues, see **Troubleshooting**. For browser or network issues, see **Browser & Proxy > Troubleshooting**.
