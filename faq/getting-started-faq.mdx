## What does BrowserAct Cloud create?

BrowserAct Cloud creates reusable Bots that automate browser tasks and return structured data.

## Where Does BrowserAct Bot Run?

BrowserAct Bots run in BrowserAct Cloud. You do not need to install software, maintain a server, or keep your computer turned on after starting a Task.

You can close the BrowserAct page or browser window while a Bot is running. Return to the Bot's `History` or open `Tasks` to check its status and results.

## Does BrowserAct handle login walls or only public pages?

Both. BrowserAct works with public pages and login-protected pages.

For a Workflow Built Bot, save and authorize the login through Credential Center. For an Agent Built Bot, sign in through human-in-the-loop assistance and use `Standard Browser` to retain the login session. Managed credentials for Agent Built Bots are coming soon.

## What is the difference between Agent Built and Workflow Built?

Both methods create a Bot.

- **Agent Built:** Describe the result you need in natural language. BrowserAct builds and tests the Bot for you.
- **Workflow Built:** Build the process yourself by connecting and configuring nodes in the visual editor.
